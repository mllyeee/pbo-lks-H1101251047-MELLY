## Deskripsi Proyek

Proyek ini merupakan hasil pengerjaan Lembar Kerja Mahasiswa (LKS) Praktikum Pemrograman Berbasis Objek dengan membangun REST API perpustakaan menggunakan PHP dan MySQL serta frontend menggunakan HTML, JavaScript, dan Tailwind CSS.

## Daftar Fitur

1. Manajemen data buku (CRUD).
2. Manajemen data kategori (CRUD).
3. REST API menggunakan PHP.
4. Database MySQL.
5. Validasi input dan penanganan error.
6. Dashboard statistik buku dan kategori.
7. Integrasi frontend dengan backend.
8. Pengujian API menggunakan cURL dan Postman.

## Cara Menjalankan Proyek

### 1. Menjalankan Backend

Buka terminal, masuk ke folder backend:

```bash
cd rest-api-perpustakaan
```

Jalankan server:

```bash
php -S localhost:8000 -t public
```

Backend berjalan di:

`http://localhost:8000`

### 2. Menjalankan Frontend

Buka terminal baru, masuk ke folder frontend:

```bash
cd frontend-perpustakaan
```

Jalankan server:

```bash
php -S localhost:3000
```

Buka browser:

`http://localhost:3000`
